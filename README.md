# Fun Rudralabh v3

Next-stage free-to-play app prototype based on the supplied reference videos and launcher design.

Added in v3:
- Login screen
- Sign-up screen
- Local player profile
- Persistent virtual-point balance using shared_preferences
- Game history in app state
- Launcher with 4 game entries
- Kuber Chakra spinning UI
- Butterfly tap game
- Joker 11 card challenge
- Lucky Card reveal
- Profile screen
- Premium dark/red/gold visual direction

Important:
This is a free-to-play entertainment prototype. It does not implement betting, deposits, wagering, withdrawals, cash-out, or real-money lottery functionality.

To run:
flutter pub get
flutter run

For production authentication, replace the local demo login with a properly configured authentication backend such as Firebase Authentication and secure server-side validation.
